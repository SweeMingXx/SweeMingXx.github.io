# Mood Garden

A tiny interactive website for a moment of calm. Choose a mood, plant a flower, and grow a colorful digital garden.

## Visit

https://sweemingxx.github.io/

## Features

- Four mood-inspired flower colors
- Click or tap to plant, with a keyboard-accessible button alternative
- Up to 60 flowers, saved locally in your browser
- Responsive layout and reduced-motion support
- No build step, analytics, or backend

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000.

## Hosting

This repository uses the GitHub Pages user-site naming convention. If Pages is not enabled automatically, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)** and save.

## Privacy

Garden state stays in browser local storage. Fonts are requested from Google Fonts; system fonts are used if the request is blocked.
