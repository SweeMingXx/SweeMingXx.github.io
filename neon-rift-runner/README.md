# Neon Rift Runner

A neon 3D arcade micro-game built with Three.js.

- **A / D** or **Left / Right** — steer
- **Space** — phase-dash through hazards
- Collect cyan shards for bonus score
- Avoid pink sentinels

## Live
https://sweemingxx.github.io/neon-rift-runner/

The game is a single static HTML page and loads Three.js from jsDelivr, so no build step is required.
