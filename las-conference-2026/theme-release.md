# Burgundy edition

The LAS Conference 2026 website now uses a deep burgundy and warm blush palette with restrained red gradients. The redesign retains the two-day programme, all fourteen uploaded report entries, the full texts, the accessible reading room, and the existing interaction design.

The visual theme is defined in `theme.css`, loaded after `styles.css`. The SVG folio and favicon use matching rose and copper tones. `tests/live.mjs` verifies that the deployed theme asset matches the repository source.
